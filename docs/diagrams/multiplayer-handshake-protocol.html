Multiplayer Lifecycle & Handshake Protocol

Sequence flow of scene transitions, late-join state recovery, and authoritative entity deduplication in Godot 4.7.2 with SteamMultiplayerPeer.

⚡ Server Authority Pattern

Server (multiplayer.is_server()) holds absolute authority over game state, timers, and physics. Clients run prediction and local rendering only.

🤝 Late-join Handshake

To eliminate RPC drops when clients load scenes slower than the host, clients actively issue request_game_sync.rpc_id(1) inside _ready().

🛡️ Entity Deduplication

All entity spawning verifies existing nodes before creating instances. Prevents duplicate avatars caused by initial broadcast + handshake re-sync.
